# AmiSoft Solutions

Partner marketing site for AmiSoft Solutions. The site speaks to consulting and systems-integration firms that sell GxP-ready computing environments and clinical and R&D data platforms.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| Solutions | `solutions.html` |
| For partners | `partners.html` |
| About | `about.html` |
| Contact | `contact.html` |

Static HTML, CSS, and JavaScript. Open `index.html` in a browser, or serve the repository root with any static file server.

## Domain

Preferred domain: **amisoftsolutions.net**

## GitHub Pages

https://atulitllc.github.io/amisoftsolutions/

Published from the `main` branch at the repository root (`/`). `.nojekyll` is present so Pages serves these files directly and does not run Jekyll.

That source is set under [Settings → Pages](https://github.com/atulitllc/amisoftsolutions/settings/pages): **Deploy from a branch**, branch **main**, folder **/ (root)**. When DNS for **amisoftsolutions.net** is ready, add that custom domain on the same screen.
